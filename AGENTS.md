# Agent workflow

For ElevenLabs audio QA, Norwegian pronunciation, multilingual voiceovers or artifact repair, read [SKILL.md](SKILL.md). It routes ordinary scans and iterative dataset work to the appropriate commands.

Run scripts from the repository root and use its virtual environment when it exists. Use a new output directory for each recording and keep the source audio intact. For a labeled study, freeze a label-free scan before using the annotations.
